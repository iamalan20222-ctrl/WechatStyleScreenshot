# WechatStyleScreenshot Cross Platform

本包提供两套实现：

- Windows：已构建好的 `WechatStyleScreenshot-self-contained-win-x64.zip`
- macOS：可在 MacBook 上构建的原生菜单栏应用源码包

## Windows 使用

解压 Windows 包，运行：

```text
WechatStyleScreenshot.exe
```

快捷键：

```text
Alt + A
```

## macOS 使用

解压 macOS 包，在 MacBook 上进入目录：

```bash
chmod +x build-and-run.command build-macos.sh install-login-item.sh uninstall-login-item.sh
./build-and-run.command
```

快捷键：

```text
Option + A
```

macOS 首次使用需要在系统设置中允许屏幕录制权限。
